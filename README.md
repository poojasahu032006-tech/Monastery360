# Monastery360 🏯

Monastery360 is a full-stack web application designed to provide a digital platform for exploring the monasteries of Sikkim.

The platform allows users to discover monasteries, view their locations on an interactive map, access detailed information, explore events and tourism-related services, and manage their user profile.

## 🎯 Problem

Information about monasteries, their locations, cultural significance, and tourism-related details can be scattered across different sources. This can make it difficult for visitors to discover and explore monasteries conveniently.

## 💡 Solution

Monastery360 brings monastery information together in a single interactive platform. Users can explore monasteries, view their locations on an interactive map, access detailed information, and navigate cultural and tourism-related resources through a user-friendly interface.

## ✨ Features

- 🏯 Explore monasteries with detailed information
- 🗺️ Interactive map with monastery locations
- 🔍 Search and filtering
- 🔐 User registration and authentication
- 👤 User profile
- 📅 Events and calendar
- 🛎️ Tourism-related services
- 📱 Responsive user interface
- 🔄 REST API based backend
- 🗄️ MongoDB database integration
